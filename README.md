# Dev-Lab

Execution engine for mini-projects, automation scripts, and hardware-AI integration.

## Arcadia

`My_Projects/A_Game.py` is a single-file terminal roguelike built with the Python standard library only.

### Run

```bash
python My_Projects/A_Game.py
```

### Controls

- `w` / `a` / `s` / `d` — move
- `attack` — attack an adjacent monster
- `g` — pick up loot
- `i` — inventory
- `e` — equip gear
- `u` — use consumables
- `t` — talk to the merchant
- `q` — quests
- `c` — crafting
- `p` — shop (while next to the merchant)
- `save` / `load` — save or restore the game
- `wait` — skip a turn
- `help` — show controls
- `exit` — quit

Arcadia includes procedural rooms and biomes, fog-of-war, A* enemy pathfinding, combat, loot, equipment, crafting, quests, a shop/economy, timed events, XP/leveling, and JSON save/load.
